# 不完全信息动态博弈口径

Search Simulator 当前不求解纳什均衡、PBE 或最优策略。它在给定公开信息规则下枚举完整行动树，并统计均匀分支语义中的终局路径分布。

## 信息不对称

- 狼人知道狼队成员；
- 好人只使用公开死亡、预言家公开信息和自身角色能力；
- 预言家未公开前，其查验只保存在私有状态；
- 预言家公开后，真实查验进入公共信息；
- 平民挡刀是用户指定的唯一虚假身份声明例外。

## 与 PBE 的关系

参考 arXiv:2408.17177v2 的扩展式贝叶斯博弈建模，但本模块没有序贯最优响应或 Bayes 信念求解器。因此 reward 区间应解释为“完整分支模拟分布”，不能标成均衡胜率。

若未来实现真正 PBE，需要在现有 GameState 之外增加：

- 信息集而非真实角色可见状态；
- 公共/私有历史的分离；
- 到达每个信息集的信念；
- 每个信息集上的序贯理性约束；
- 离轨信念更新规则。
