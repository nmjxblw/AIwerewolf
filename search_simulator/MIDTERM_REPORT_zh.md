# 中期汇报：狼人杀廉价磋商的精确信念收益矩阵

## 摘要

本中期报告阐述团队为狼人杀构建的精确信念、模型条件收益矩阵及其初步验证结果。研究对象为廉价磋商（cheap talk），即具有策略相关性但不受规则强制约束的公开交流，并考察其对玩家信念、后续投票及不完全信息零和博弈终局效用的影响。长期目标包括比较矩阵的事前估计与重复真实对局结果，以及将结构化数值作为语言模型智能体的可解释决策依据。鉴于当前尚无真实对局数据，本报告的范围限定为数学设计、已实现的评价流程和初步模拟输出；经验校准属于后续研究阶段。

方法设计以两层建模替代完整未来博弈树枚举。完整分支树迭代仍适用于小规模规则验证，但隐藏角色、顺序发言、逐人投票、夜间技能和规则随机性将导致未来状态空间的组合增长。信念层对有限合法隐藏站位进行精确条件化；决策层从完整后验分布（posterior）中抽取隐藏世界，并在显式功利等级策略下执行前向终局蒙特卡洛（Monte Carlo）模拟。该划分对当前可控状态保留精确推理，仅对组合规模不可控的未来过程实施受控近似。

当前实现针对每个具体结构化发言动作，在三档证据强度下生成收益矩阵。每个单元格输出终局效用估计、蒙特卡洛标准误、相对“矩阵对照动作”（matrix baseline）的配对差以及反应情景计数。初步案例显示，动作收益不仅取决于是否作出预言家身份声明，还取决于行动者角色、发言目标、声称的查验结果及发言证据强度。上述结果仅具有模型条件语义，不构成均衡结论，也尚未被验证为人类或语言模型的真实行为规律。

## Situation：研究背景与问题

狼人杀包含私有身份、非对称信息、公开交流和延迟后果。不受规则约束的声明仍可能改变信念、票型和终局效用。因此，本研究将问题表述为：在特定角色依法可获得的信息条件下，对备选发言动作进行事前效用评价。

本研究以 Shitong Wang 的《Optimal Strategy in the Werewolf Game: A Theoretical Study》为理论基础。该论文基于零和胜率、改进的“random strategy+”、不完全信息建模，以及诚信约束下预言家隐藏或公开信息的递归决策建立分析框架，并将非诚信交流、顺序发言和角色扩展列为开放研究方向。本项目将该框架扩展至多个角色在顺序环境中的结构化真实或欺骗性发言。基石论文的均衡结论不被直接外推至扩展后的博弈设定。

完整未来树不适合作为主要评价器。隐藏站位、发言目标、投票、角色技能、平票和后续反应将产生组合爆炸，且结构路径数不具有行为概率语义。语言模型重复对局还具有计算成本较高、提示词敏感和可能固化有限历史偏好的问题。上述限制要求采用动作级受控估计器，而非完整路径计数或对单一模型行为的经验拟合。

为建立可计算边界，当前研究采用七人固定角色配置：两名狼人、两名平民、一名女巫、一名预言家和一名守卫，共形成 1260 种合法隐藏站位。当前阶段集中研究第一天公开发言，包括平民虚假声明预言家身份以分担真实预言家风险、预言家沉默、狼人虚假声明预言家身份、普通指控、支持、投票意向和中性对照动作。该固定配置不代表全部狼人杀变体，而是信息边界与动作边界均可形式化、检查和复现的有限实验环境。

## Task：阶段任务

团队的中期任务是构建收益矩阵，用于估计以下条件下的期望终局效用：公开状态、行动者私有知识、合法隐藏世界的精确后验分布、具体发言干预及固定未来行为模型。每个单元格均须具有稳定语义，在匹配随机条件下与矩阵对照动作比较，报告数值不确定性，并保持对进程数和执行顺序的可复现性。矩阵显式保留全部同级目标，同时将旁观者完整信息排除在角色约束查询之外。

本阶段交付内容包括决策发生前的收益矩阵及初步模拟证据。后续经验研究将通过 API 采集真实对局，并比较预测值与重复对局结果。由于相关数据尚未形成，本报告不作已完成真实对局拟合或外部验证的结论。

## Action：方法设计与执行

### 矩阵结构与输出契约

矩阵由行动者、具体动作和证据强度共同索引。每一行是完整二级发言动作，而不是宽泛战术标签；每一列对应一个证据强度档位。单元格定义为：

$$
\mathcal M^{(i)}_{a,c}
=
\left(
\widehat V_N^{(i)}(a,c),
\operatorname{SE}_N(a,c),
\widehat\Delta_N^{(i)}(a,c),
\operatorname{SE}_{\Delta,N}(a,c),
N,
\mathbf n_{\mathrm{scenario}}
\right).
$$

| 符号 | 定义 |
| --- | --- |
| `\mathcal M^{(i)}_{a,c}` | 行动者 `i`、具体动作 `a` 与证据强度 `c` 所共同确定的矩阵单元格 |
| `i` | 当前行动者的索引；其合法信息与阵营效用共同确定评价视角 |
| `a` | 对应矩阵一行的具体结构化发言动作 |
| `c` | 对应矩阵一列的证据强度参数；当前评价档位为 0、0.5 和 0.8 |
| `\widehat V_N^{(i)}(a,c)` | 行动者 `i` 在动作 `a` 和证据强度 `c` 下期望终局效用的蒙特卡洛估计 |
| `\operatorname{SE}_N(a,c)` | 终局效用估计的蒙特卡洛标准误 |
| `\widehat\Delta_N^{(i)}(a,c)` | 动作 `a` 相对矩阵对照动作的平均配对效用差估计 |
| `\operatorname{SE}_{\Delta,N}(a,c)` | 配对效用差估计的标准误 |
| `N` | 该单元格模拟的终局轨迹数；生产规范固定为 100 |
| `\mathbf n_{\mathrm{scenario}}` | 由六个互斥反应情景计数组成的向量 |

矩阵输出采用多维统计量，而非聚合后的单一策略分数。输出内容包括终局效用估计、蒙特卡洛标准误、相对矩阵对照动作的配对差及其标准误、样本数和六类反应情景计数。三档证据强度分别保留；一级动作族仅作为导航摘要，不参与跨动作平均。

### Baseline（对照动作）的操作定义

矩阵 baseline 被操作性定义为：行动者进入预定发言轮次，但不施加任何待评价战术干预。该中性结构化事件不包含指控目标、支持目标、投票意向、身份声明、声称的查验结果或战术标签，且沟通强度为零。事件仅推进正常发言顺序，不编码自然语言语句，并在动作标识层面与显式沉默保持区分。

| 名称 | 操作定义 | 用途 |
| --- | --- | --- |
| 矩阵对照动作 | 行动者经过正常发言轮次，但不加入战术内容 | 估计各候选动作相对该参照的配对效用差 |
| 显式沉默 | 独立候选动作，表示行动者主动不提供公开内容 | 将沉默作为独立策略动作进行评价 |
| 实验对照组 | 后续整局实验中不启用平民或狼人虚假声明预言家身份的处理，真实预言家仍须提供有效发言 | 估计重复真实对局中的组间处理效应 |

在当前抽象下，中性 baseline 与显式沉默可能产生相同的数值估计。二者仍具有不同的实验语义：前者表示待评价战术干预的缺省参照，后者表示纳入候选排名的显式策略动作。

匹配比较要求候选动作与矩阵对照动作共享相同的公开状态、角色视角、隐藏站位样本和后续随机流。因此，配对差估计的是在给定模型下，以候选动作替换中性对照动作所导致的终局效用变化。baseline 不具有跨对局通用的固定胜率含义，其数值由行动者、角色信息、局势、证据档位和未来行为模型共同决定。结果表中的 -0.4 仅适用于对应矩阵行及实验条件。

### 分离精确信念与未来模拟

该方法将当前信息不确定性与未来状态空间的组合增长分离。在固定角色配置中，信念层枚举全部 1260 种合法角色站位，排除与行动者信息不相容的隐藏世界，并对剩余权重进行归一化。给定上一时刻信念与新证据似然，行动者的精确后验分布为：

$$
B_t^{(i)}(\theta)
=
\frac{B_{t-1}^{(i)}(\theta)L_t^{(i)}(\theta)}
{\sum_{\theta'}B_{t-1}^{(i)}(\theta')L_t^{(i)}(\theta')}.
$$

| 符号 | 定义 |
| --- | --- |
| `B_t^{(i)}(\theta)` | 行动者 `i` 在决策时刻 `t` 对隐藏角色站位 `\theta` 赋予的后验概率 |
| `B_{t-1}^{(i)}(\theta)` | 纳入当前证据之前，行动者对站位 `\theta` 的信念 |
| `L_t^{(i)}(\theta)` | 在站位 `\theta` 下出现新增观测证据的似然，并按行动者 `i` 的信息视角计算 |
| `\theta` | 有限状态空间中的一个完整合法隐藏角色站位 |
| `\theta'` | 对行动者信息约束下全部合法站位求和时使用的索引 |
| `t` | 顺序决策或证据更新的时刻索引 |

后验分布不使用蒙特卡洛近似，也不采用 top-k 截断。随后，系统从完整后验分布中抽取隐藏世界，并由固定功利等级策略生成直至终局的轨迹。具体发言动作的价值定义为：

$$
V^{(i)}(a,c)
=
\mathbb E_{\Theta\sim B_t^{(i)},\;\tau\sim P_{\rho,c}(\cdot\mid do(a),\Theta,I_t^{(i)})}
\left[u_i(\tau)\right].
$$

| 符号 | 定义 |
| --- | --- |
| `V^{(i)}(a,c)` | 行动者 `i` 的理论模型条件期望终局效用，是模拟样本均值所估计的目标量 |
| `\mathbb E` | 同时对隐藏世界不确定性和随机未来轨迹求期望的算子 |
| `\Theta` | 从行动者 `i` 的精确后验分布中抽取的随机隐藏角色站位 |
| `\tau` | 从当前干预开始延伸至终局的随机模拟轨迹 |
| `P_{\rho,c}` | 由策略 `\rho`、证据强度 `c` 及显式规则随机性共同诱导的未来轨迹分布 |
| `\rho` | 控制未来模拟动作的固定功利等级策略 |
| `do(a)` | 在保持初始条件不变的情况下，以具体动作 `a` 替换行动者当前发言事件的干预算子 |
| `I_t^{(i)}` | 行动者 `i` 在决策时刻 `t` 依法可获得的公开与私有信息 |
| `u_i(\tau)` | 轨迹 `\tau` 的行动者阵营终局效用；本阵营获胜为 +1，失败为 -1 |

该数值是从行动者信息视角出发、在决策发生前得到的模型条件价值。

每名行动者具有独立的角色视角。所有玩家知道自身身份；狼人知道其狼队友；预言家仅知道既有查验所得的好人或狼人阵营结果，而不知道好人目标的具体角色。公开身份声明、未公开角色的死亡、主观怀疑和较高后验概率均不得转化为身份硬知识。完整隐藏站位仅供研究者审计，矩阵输入校验将拒绝该信息。由此形成两个概念层面的 API 通道：用于后续验证的旁观者通道，以及用于动作计算的角色约束通道。

### 将自然语言转化为可比较动作

系统以结构化发言计划替代完整自然语言。当前一级动作族包括中性 baseline、指控、支持、投票意向、预言家身份声明和显式沉默。一级类别仅用于摘要和导航，不构成实际评价单元。每个二级具体动作保留具有策略意义的字段：目标席位、身份声明、声称的查验目标和阵营结果、沟通强度及战术标签。完整的虚假预言家声明必须指向另一名存活玩家，并声明该玩家属于好人或狼人阵营；仅声明身份而不提供查验结果构成单独的弱声明；真实预言家仅可公开其实际私有查验；预言家沉默被表示为显式空发言事件，而非错误或占位文本。

该抽象舍弃具体措辞、语言风格和提示词文本，同时保留可能影响信念与后续投票的语义成分。不同的预言家身份声明不会被合并为单一数值。所有同级目标均进入矩阵，席位顺序不作为同级动作的任意裁决规则。

### 建模证据强度与未来行为

当前证据强度固定为 0、0.5 和 0.8。上述取值是敏感性分析的参考点，不表示声明为真的概率。发言似然通过中性似然插值得到：

$$
L_c(e\mid\theta)
=
(1-c)+cL_{\mathrm{speech}}(e\mid\theta),
\qquad
c\in\{0,0.5,0.8\}.
$$

| 符号 | 定义 |
| --- | --- |
| `e` | 纳入信念更新的结构化发言证据事件 |
| `L_{\mathrm{speech}}(e\mid\theta)` | 隐藏站位 `\theta` 下对证据 `e` 赋予的基础发言似然 |
| `L_c(e\mid\theta)` | 按证据强度 `c` 插值后得到的证据似然 |
| `c` | 取值范围为 0 至 1 的插值强度；本研究评价 0、0.5 和 0.8 三档 |
| `1-c` | 分配给单位中性似然的权重；当 `c=0` 时，发言事件不提供身份识别证据 |
| `\theta` | 当前评价的候选隐藏角色站位 |

因此，零档表示忽略发言身份信息，中档和高档分别表示中等与较强的证据影响。三档独立展示，未来可以使用真实对局或语言模型信念更新进行校准。

未来模拟玩家不调用语言模型，也不递归构造新的收益矩阵。系统采用显式功利等级策略，依次处理游戏硬规则、实验战术约束、阵营目标、身份能力优先级和同级动作。五档规范分数 1、0.75、0.5、0.25 和 0 通过固定 softmax 函数转换为行动概率：

$$
\pi_{\rho}(a\mid s,i)
=
\frac{\exp\left(Q_i(s,a)/\tau_{\mathrm{policy}}\right)}
{\sum_{a'\in\mathcal A_i(s)}\exp\left(Q_i(s,a')/\tau_{\mathrm{policy}}\right)},
\qquad
\tau_{\mathrm{policy}}=0.25.
$$

| 符号 | 定义 |
| --- | --- |
| `\pi_{\rho}(a\mid s,i)` | 策略 `\rho` 在状态 `s` 中为行动者 `i` 选择动作 `a` 的概率 |
| `s` | 当前模拟决策状态 |
| `\mathcal A_i(s)` | 行动者 `i` 在状态 `s` 中的合法动作集合 |
| `a'` | 对合法动作集合求和时使用的索引 |
| `Q_i(s,a)` | 动作 `a` 的规范化功利等级分数；允许值为 1、0.75、0.5、0.25 和 0 |
| `\tau_{\mathrm{policy}}` | 控制等级动作概率离散程度的 softmax 温度；固定为 0.25，且与证据强度相互独立 |
| `\exp` | 将等级分数转换为正值并归一化的指数函数 |

该策略是透明的行为假设，不来自历史对局拟合，也不被描述为均衡或真实人类行为模型。

### 公平估计终局收益

对于每个具体动作和每档证据强度，生产规范固定模拟 100 条直至终局的轨迹。好人行动者在好人阵营获胜时获得 +1、狼人阵营获胜时获得 -1；狼人行动者使用相反符号。收益估计与蒙特卡洛标准误为：

$$
\widehat V_N^{(i)}(a,c)
=
\frac{1}{N}\sum_{n=1}^{N}u_i\left(\tau_n^{a,c}\right),
\qquad
\operatorname{SE}_N(a,c)=\frac{s_N(a,c)}{\sqrt N}.
$$

| 符号 | 定义 |
| --- | --- |
| `n` | 从 1 至 `N` 的轨迹样本索引 |
| `\tau_n^{a,c}` | 动作 `a`、证据强度 `c` 和样本索引 `n` 所对应的终局轨迹 |
| `u_i(\tau_n^{a,c})` | 行动者 `i` 在该轨迹上实现的终局效用 |
| `\widehat V_N^{(i)}(a,c)` | `N` 个终局效用的算术平均值，用于估计理论值 `V^{(i)}(a,c)` |
| `s_N(a,c)` | `N` 个终局效用样本的样本标准差 |
| `\operatorname{SE}_N(a,c)` | 有限蒙特卡洛抽样产生的标准误，等于样本标准差除以 `N` 的平方根 |

系统使用共同随机数将候选动作与矩阵对照动作配对。在相同证据档和样本索引下，所有候选共享隐藏世界抽样、后续行动随机流、平票随机数和其他规则随机源。下式第二项中的参照动作，就是上文定义的矩阵对照动作。配对收益差为：

$$
\widehat\Delta_N^{(i)}(a,c)
=
\frac{1}{N}\sum_{n=1}^{N}
\left[u_i\left(\tau_n^{a,c}\right)-u_i\left(\tau_n^{a_0,c}\right)\right].
$$

| 符号 | 定义 |
| --- | --- |
| `\widehat\Delta_N^{(i)}(a,c)` | `N` 组样本内候选动作与矩阵对照动作效用差的平均值 |
| `a_0` | 前文定义的矩阵对照动作 |
| `\tau_n^{a_0,c}` | 与候选轨迹共享证据强度、样本索引、隐藏世界和随机流的对照轨迹 |
| `N` | 候选动作与矩阵对照动作的配对轨迹比较数量 |

把每条轨迹的配对结果差记为一个样本值，其标准误为：

$$
d_n(a,c)
=
u_i\left(\tau_n^{a,c}\right)-u_i\left(\tau_n^{a_0,c}\right),
\qquad
\operatorname{SE}_{\Delta,N}(a,c)
=
\frac{1}{\sqrt N}
\sqrt{\frac{1}{N-1}\sum_{n=1}^{N}
\left[d_n(a,c)-\widehat\Delta_N^{(i)}(a,c)\right]^2}.
$$

| 符号 | 定义 |
| --- | --- |
| `d_n(a,c)` | 第 `n` 组样本中候选动作效用减去矩阵对照动作效用所得的差值 |
| `\widehat\Delta_N^{(i)}(a,c)` | 全部配对差值的样本均值 |
| `d_n(a,c)-\widehat\Delta_N^{(i)}(a,c)` | 单个配对差值相对于配对样本均值的离差 |
| `\operatorname{SE}_{\Delta,N}(a,c)` | 配对差均值的标准误，由 `N` 个配对差值的样本方差计算 |
| `N-1` | 无偏样本方差估计所使用的自由度分母 |

该配对设计可降低差值估计的方差，并限制不同动作之间随机隐藏世界不均衡所造成的混杂。

每条轨迹还按固定优先级归入六个互斥解释情景之一：行动者反噬、目标成功转移、声明被接受、声明受到争议、发言被忽略或其他。默认信念变化阈值为 0.05。这些计数用于解释模拟机制，不参与收益计算或行动选择。

### 构建可复现的研究工具

隔离工作进程（worker）按批次同时评价全部候选，仅返回充分统计量，从而在不传输完整轨迹的情况下保留配对随机性。有界队列形成背压，单一写入者对批次进行幂等提交。请求身份覆盖游戏状态、行动者视角、后验分布、候选集合、策略、证据档位、样本数和种子方案。完整请求可复用，中断请求按原样本索引和种子恢复。

只有在每个具体动作具备三档证据单元、每格达到目标样本数、情景计数之和等于样本数、矩阵对照动作存在、配对样本一致，且已提交样本区间无缺口或重叠时，矩阵才能标记为完整。部分或失败结果不会作为完整排名输出。

## Result：当前结果

当前管线已经能够通过命令行、图形界面和 Python API 输出完整的“动作×证据强度”矩阵。一个采用生产预算的七人预言家请求评价了 22 个动作和 3 档证据，共形成 66 个单元格，每格 100 条终局轨迹，效用估计范围为 -0.58 至 -0.34。另一份探索性报告使用每格 10 条轨迹，覆盖十种不同的行动者可见视角，共完成 308 个动作行和 924 个单元格。

| 矩阵观察 | 记录数值 | 允许作出的解释 |
| --- | --- | --- |
| 零证据控制档 | 大部分动作与各自的中性对照相同 | 被忽略的发言很少通过信念通道改变收益。 |
| 平民虚假声明预言家身份案例，高证据档 | 矩阵对照为 -0.4；特定虚假声明为 +0.4；配对差为 +0.8 | 以特定目标和声明结果替换中性动作后，动作效用估计由负值变为正值。 |
| 狼人虚假声明预言家身份案例，高证据档 | 矩阵对照为 +0.6；特定虚假声明为 +1.0；配对差为 +0.4 | 在固定策略下，效用估计随目标身份而变化；指向已知狼队友的声明可能降低效用。 |
| 预言家持有狼人查验结果 | 中、高证据档的配对差均为 +0.4 | 在该信息状态中，真实公开查验产生正向配对估计；相应的好人查验案例未出现相同差值。 |

初步结果表明，动作族和证据强度均不能独立决定收益；角色视角、目标、声明阵营与证据强度共同影响效用估计。较高证据强度并不一致地对应较高效用，因此，将预言家身份声明动作族聚合为单一全局数值会消除与决策相关的异质性。

上述数值属于说明性案例，不构成结论性证据。每个单元格仅包含 10 条轨迹，标准误最高约为 0.33。相关结果用于展示模型敏感性和矩阵解释方法，不能支持欺骗行为提高真实对局胜率的推断。

矩阵实现的可靠性验证显示，相同请求在使用 1、2 和 4 个工作进程时所得结果逐值一致；确定性终局案例与解析值一致；十组多站位输入均保留全部证据单元，且所有情景计数均等于相应样本总数。输入校验能够拒绝完整隐藏站位、矛盾角色知识和非法动作。共 65 项模块测试通过，覆盖矩阵构建、信息隔离、确定性采样、持久化、查询和中断恢复。

## 局限与下一阶段

当前矩阵评价对象为明确定义的模拟分布，而非真实人类或语言模型行为。未来行为策略由人工规范，证据强度尚未经过经验校准，研究板子与博弈阶段均被固定，且当前不存在真实对局比较数据。因此，本阶段证据仅支持团队已构建可复现、可解释的评价工具，不支持关于普适最优廉价磋商策略的结论。

下一阶段将通过游戏 API 记录每次决策前的公开状态、行动者合法视角、实际发言、后续票型和终局结果，并将真实发言映射至同一结构化动作表示。受控重复实验将估计整局处理组与实验对照组之间的效应差；匹配后的真实动作记录用于比较矩阵的事前效用及其相对矩阵对照动作的配对差。自然语言模型对局将用于评估外部适用性。经校准的信念更新可在后续阶段替代当前证据强度参考点，收益矩阵亦可作为结构化决策依据提供给智能体。上述阶段构成从数学评价、实际对局观测到可解释智能体决策的研究路径。
