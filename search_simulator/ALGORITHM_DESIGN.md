# 在线区间极大极小决策算法设计

> 本文档是「在线决策参考算法」的**算法设计**（概念、公式、语义、边界与假设）。
> 具体的新增文件、现有文件改动与测试见 **`CODE_CHANGES.md`**。

## 1. 命名与关键参数对照

| 名称 | 正式算法名 / 含义 |
|---|---|
| 主干 | **区间极大极小搜索（Interval Minimax Search）**：零和完美信息博弈的经典 **极小极大（Minimax）**，节点值用 reward 区间表示 |
| 整体 | **在线区间极大极小决策（Online Interval-Minimax Decision）** |
| **λ** | **迭代风险参数**：在「对抗（并集/交集）」与「随机（均值）」之间折中；`λ ∈ [0,1]` |
| **toggle** | **乐观/保守开关**（本质是**放缩设计**）：乐观 = **放大**（并集，宽区间），保守 = **缩小**（交集，窄区间） |
| **lookahead_depth** | **前瞻深度**（按决策点计：night=1 层、day=1 层）；`None` = 全深度（递归到真终局，带环检测兜底） |
| ~~区间值矩阵博弈~~ | **optional**：v1 不实现（见 §5） |

## 2. 背景与目标

现有 `SearchSimulator` 做的是**全树穷举搜索**：

- `_resolve_night` 枚举「狼刀 × 守卫 × 女巫 × 预言家查验」所有组合；
- `_resolve_day_vote` 枚举所有放逐结果；
- `_check_game_over` 判定胜负，终局按 `wins` 计数。

关键结论：当前树是**完全信息**的（`GameState` 内 `Player.role` 已知），枚举的是「行动分支」而非「隐藏身份分支」；终局统计本质上是**随机走法的胜率**，**不是零和极小极大（minimax）的策略价值**。

本算法要补上「策略价值」这一层：把狼人杀抽象为**好人阵营 vs 狼人阵营的零和博弈**，通过 **reward 区间** 比较候选行动、选出一个参考行动。

> 与 `gametheory.md` 的「不完全信息动态博弈」笔记关系：本文档是**完全信息抽象**下的确定性零和决策基线；「不完全信息 / CheapTalk 信号 / 似然计算」属于后续扩展方向，暂不纳入 v1。

**成功标准**

1. `SearchSimulator(policy="online", ...)` 从根状态沿参考路径逐步决策到**真终局**，输出结构化 trace（每步双区间 + 选中行动）。
2. 值区间随前瞻深度单调收紧，λ=1、全深度时夹住精确 minimax 值；λ=0 时坍缩为区间均值。
3. 现有 `policy="exhaustive"` 默认路径行为零回归。
4. 测试覆盖 phase、transition、λ 回传、toggle（并集/交集）、区间算术、阵营抽象、minimax、在线驱动、战术门控、合法性校验、i18n。

## 3. 核心抽象

- **两个敌对对象**：`Camp.GOOD`（好人阵营）与 `Camp.WOLF`（狼人阵营）。
  - 角色映射：狼人 / 白狼王 → WOLF；村民 / 预言家 / 女巫 / 守卫 / 猎人 → GOOD。
- **零和**：统一以「好人视角」计分。
- **值域（仅两类，无 `0` 数值）**：
  - 终局：好人胜 `+1` / 狼人胜 `-1`（退化区间 `[u, u]`）。
  - 未决（前沿/深度耗尽/退化环）：**`[-1, +1]`**（全不确定，保证夹住真值）。
  - `0` 仅作为**报告层展示标签**（「未分胜负」），**不进回传**。
- **终局价值**：由 `_check_game_over` 结果字符串映射——含「好人」→ `+1.0`，否则（三套狼胜文案）→ `-1.0`。

## 4. reward 区间语义（λ-稳健回传 + toggle 放缩）

把狼人杀当成一棵**扩展式（时序）零和博弈树**。因为 **GameState 的迭代不是完全随机的**（对手会针对你，而非均匀随机），纯均值（随机走法）低估对抗性；纯 min/max（全对抗）又过度悲观/乐观。因此引入**迭代风险参数 λ** 在「对抗」与「随机」之间折中，并用 **toggle** 决定「乐观（并集）还是保守（交集）」。

### 4.1 节点值 = reward 区间（区间回传）

每个节点向上回传一个 **reward 区间 `[lower, upper]`**，**两个界都保留、不坍缩成单标量**（避免丢弃任何判断）。

```python
RewardInterval(lower, upper)   # -1 <= lower <= upper <= +1
```

### 4.2 叶子节点

```
终局                -> [u, u]      (u = +1 好人胜 / -1 狼人胜)
前沿(深度耗尽,非终局)  -> [-1, +1]    (未决，全不确定)
退化环(路径重复)      -> [-1, +1]    (未决，停止该分支)
```

### 4.3 内部节点聚合（λ + toggle）

子节点区间 `[lower_i, upper_i]`（i = 1..n）：

```
mean_lower = (1/n) · Σ lower_i
mean_upper = (1/n) · Σ upper_i

乐观（optimistic，并集 union）:
  lower = λ · min_i(lower_i) + (1-λ) · mean_lower
  upper = λ · max_i(upper_i) + (1-λ) · mean_upper

保守（conservative，交集 intersection）:
  lower = λ · max_i(lower_i) + (1-λ) · mean_lower
  upper = λ · min_i(upper_i) + (1-λ) · mean_upper

节点区间 = [lower, upper]
```

### 4.4 λ 与 toggle 语义

- **λ**：`λ=1` → 纯并集/交集（最宽/最窄）；`λ=0` → 坍缩为 `[mean_lower, mean_upper]`（区间均值，弱启发式）；`0<λ<1` 折中。
- **toggle**：
  - 乐观（optimistic）→ **放大 / 并集**：`[min(lower_i), max(upper_i)]`（全跨度，最宽，λ=1 时）。
  - 保守（conservative）→ **缩小 / 交集**：`[max(lower_i), min(upper_i)]`（共识重叠，最窄，λ=1 时）。

> **例子**：`v1 = (-0.2, 0.8)`，`v2 = (-0.5, 0.5)`，λ=1：
> - 乐观 → `(-0.5, 0.8)` = `[min(-0.2,-0.5), max(0.8,0.5)]`（并集）
> - 保守 → `(-0.2, 0.5)` = `[max(-0.2,-0.5), min(0.8,0.5)]`（交集）
>
> **放缩（scaling）视角**：toggle 是对 reward 区间的**放缩设计**——乐观 = **向外放大**到全跨度（并集，对不确定性的高估/上界），保守 = **向内缩小**到共识（交集，对不确定性的低估/下界）；故有 sandwich 性质 **保守区间 ⊆ 真实区间 ⊆ 乐观区间**。该设计**略显反直觉**（乐观下界更负、保守下界更好），但**有意保留两个界**。

### 4.5 反向传播

从叶子自底向上，逐层用 §4.3 公式聚合子节点区间，回传到当前节点；根节点的区间即整局的稳健价值范围。

## 5. 区间值矩阵博弈（optional，v1 不实现）

> **标记 optional**：v1 采用「夜晚 `_resolve_night` 全枚举 + §4.3 普通合并」，与白天完全同构、价值回传阵营无关，无需矩阵。
>
> **设计风险 / 开销说明**：区间矩阵需对下界矩阵 `L`、上界矩阵 `U` 分别求极小极大；无纯策略鞍点（`maxmin ≠ minmax`）时需混合策略/线性规划，实现与运算开销大，且与「阵营无关合并」语义冗余。故 v1 不做；若未来需要显式刻画「双方同时行动」的对抗结构，再按本节实现。

（参考实现形态，暂不落地）

```
       狼:刀X    狼:刀Y
好:守X  [.., ..]  [.., ..]
好:守Y  [.., ..]  [.., ..]
```

- 行 = 狼刀目标；列 = 好人联合行动（守卫 × 女巫）；cell = 递归区间；下/上界矩阵分别求极小极大得 `[V_min, V_max]`。

## 6. 算法细节

### 6.1 统一价值尺度

- 一律好人视角：好人胜 `+1.0`，狼人胜 `-1.0`。
- 未决（前沿/环）→ `[-1, +1]`。
- 狼人控制节点对价值取负号（最小化好人的价值）。

### 6.2 聚合公式（区间回传 + λ + toggle）

- 乐观：`lower = λ·min_i(lower_i)+(1-λ)·mean(lower_i)`；`upper = λ·max_i(upper_i)+(1-λ)·mean(upper_i)`。
- 保守：`lower = λ·max_i(lower_i)+(1-λ)·mean(lower_i)`；`upper = λ·min_i(upper_i)+(1-λ)·mean(upper_i)`。
- 价值回传**阵营无关**（每个节点都用同一聚合公式）；阵营只在「选行动」体现。

### 6.3 白天 vs 夜晚的分工

**白天** = 单方决策（抽象为「好人阵营选放逐目标」，狼票折进区间）：

```
对每个放逐目标 e:
    child = transition(放逐 e 后的状态)
    interval(e) = evaluate(child, depth-1, WOLF, ...)
节点区间 = merge([interval(e)], toggle, λ)
参考路径：白天以好人为主 → 取好人价值最大者
```

**夜晚** = 双方同时行动 → `_resolve_night` 全枚举 + §4.3 普通合并（**无矩阵**）：

```
children = _resolve_night(state)   # 含骗刀/空刀等战术分支
节点区间 = merge([interval(c)], toggle, λ)
参考路径：夜晚以狼为主 → 取好人价值最小者
```

死亡连锁分支（猎人开枪 / 白狼王带走）作为**普通子分支**纳入合并，**无特殊 max/min 规则**。

### 6.4 决策比较（toggle）

| toggle | 比较用（子区间的哪个界） | 好人（白天） | 狼人（夜晚） |
|---|---|---|---|
| `optimistic`（乐观） | **上界** `upper_i` | 取最大 | 取最小 |
| `conservative`（保守） | **下界** `lower_i` | 取最大 | 取最小 |

> λ 与 toggle 解耦：**λ 决定区间宽度（稳健度）**，**toggle 决定「并集/交集聚合 + 看哪个界」**。

### 6.5 在线参考驱动（深度驱动）

```
state = 根状态 (phase="night")
while not 终局:
    candidates = oracle.transition(state)      # 封装迭代更新
    (chosen, interval) = 决策(candidates, ...)  # 白天=好人为主 / 夜晚=狼为主
    trace.append({step, phase, camp, candidates, chosen_action, optimistic_interval, conservative_interval, chosen_interval})
    state = canonical 物化(chosen)
```

- **深度驱动**：**无步数上限**；`lookahead_depth` 为唯一前瞻控制（`None`=全深度）。正常对局必然终止（白天必放逐 → 人口递减 → 终局）。
- **退化环保护**：空刀 + smart_vote 无有效投票等极端组合可能原地循环；用**当前路径签名去重**检测，遇重复签名 → 该分支按前沿 `[-1,+1]`（未决）停止，不判胜负。
- **trace 双区间**：每步同时存 `optimistic_interval`（并集）与 `conservative_interval`（交集），`chosen_interval` = 当前 toggle 者；区间显示 4 位小数、JSON 保留 float。

### 6.6 精确对照（regret）

`--compare_with_exact` 时，以**同一算法、全深度（`depth=None`，同 λ/toggle/战术）**重算各决策点的精确价值与最优行动集：

- `regret = exact_value - online_value`（根节点 + 逐决策点）
- `action_agreement_rate`：在线选中行动落在精确最优集的比例

### 6.7 夜间战术（战术开关，night-only）

战术仅影响**夜晚分支枚举**（白天是搜索算法的选票聚合，不做战术）。当 `--smart_vote` 勾选时，GUI 用**父级勾选 + 缩进子勾选**（原生 Checkbutton 树，勾选与展开分离）枚举以下战术（可勾选开启）：

| 战术 | 阵营 | 效果（新增分支） | 触发条件 |
|---|---|---|---|
| 骗刀 | 狼 | 狼人可选目标集从「所有非狼」扩展为「所有存活玩家」（刀任一狼，含自己） | 存活女巫存在 且 解药 > 0 |
| 空刀 | 狼 | 狼人可选**不刀人**（`wolf_target=None`，本夜无狼刀死亡；女巫毒仍可杀人） | 任意夜 |

> **好人阵营夜间行动已完全枚举**（守卫：全目标 + 空守；女巫：救/毒/无；预言家：查验 + 不查），因此无需新增好人分支战术；如需好人「策略剪枝」（如女巫首夜必救、守卫守神职），可作为后续「策略偏好」单独扩展，不纳入本战术树。

## 7. 边界情况与失败模式

1. **空候选**：白天存活 ≤1 或夜晚无刀口 → 直接返回终局/未决区间。
2. **区间不变量**：构造与合并强制 `lower <= upper`，并夹取到 `[-1, +1]`；NaN/inf 防护。
3. **交集退化**：保守模式下若子区间无重叠（`max(lower_i) > min(upper_i)`），λ<1 时取均值兜底；λ=1 时区间倒置 → 交换为 `[min(upper), max(lower)]` 并日志标注。
4. **λ 越界**：`lambda_risk` 夹取到 `[0, 1]`；`λ=0` 区间坍缩为 `[mean_lower, mean_upper]`，`λ=1` 为纯并集/交集。
5. **退化环**：路径签名重复 → 按前沿 `[-1,+1]` 停止，不判胜负（深度驱动无步数上限）。
6. **零和一致性**：价值全程好人视角，狼人节点负号化；终局映射用「好人」子串。
7. **性能**：bounded depth ≤3 在 5–8 人板可接受；全深度对照仅限极小板（约 3–4 人、1 狼）。
8. **可复现**：v1 全程确定性（稳定排序 + 首个最大 tie-break），无随机 rollout。
9. **回归**：`policy` 默认 `exhaustive`，`run()` 分支未动；新增方法仅增不改。
10. **战术合法性**：骗刀仅在女巫解药可用时产生；空刀任意夜；战术全关时狼人只能刀非狼（与现状一致）。

## 8. 显式假设

- **A1 完全信息**：与现有模拟器一致，`GameState` 内角色已知；v1 不建模隐藏身份，区间只反映「行动/对抗」不确定性。
- **A2 白天抽象**：白天视为「好人阵营选放逐」，狼票影响折入区间。
- **A3 夜晚抽象**：`_resolve_night` 全枚举 + §4.3 普通合并（无矩阵；矩阵博弈标 optional）。
- **A4 预言家查验**：在线评估中预言家**不查验**；查验结果仅作为「起始状态里用户输入的身份探知」存在。
- **A5 canonical 物化**：选中行动的多条死亡连锁/查验分支，取确定性首个分支生成参考路径。
- **A6 「作为参考」口径**：默认「可读 trace + 可选精确对照（regret / 行动吻合率）」。
- **A7 phase/day_count**：根状态 `phase="night"`；夜晚结算后 `"day"`、白天结算后 `"night"` 且 `day_count` 自增；`phase` 与 `day_count` 纳入 `_state_signature`。
- **A8 区间回传**：节点值 = 区间 `[lower, upper]`（留两界）；聚合用 §4.3 并集（乐观）/ 交集（保守）+ λ。
- **A9 GUI**：λ slider `[0,1]`（带实时标签）、toggle 开关、phase 显示、reward 区间展示、可视化自定义状态编辑器、战术勾选树（父级+子勾选）、迭代树自定义分层预览（Canvas + `▸/▾` 展开器）、三栏弹性布局、i18n(t()) + hover。
- **A10 战术范围**：仅夜间、仅狼人分支（骗刀/空刀）；好人夜间行动已完全枚举。
- **A11 自定义状态 parent/depth**：GUI 输入 `parent_state_id=None`、`depth=0`；仅 API 传入保留 parent 链。
- **A12 i18n**：文案统一走 `t(key, *args, **kwargs)`（取文本 + f-string 式格式化）+ `set_language(lang)`；默认 `zh-CN`（语言切换隐藏）；缺 key 回退 key 本身；领域数据（角色/技能/胜负串/phase 机器值）不翻译。
- **A13 深度驱动**：无步数上限；`lookahead_depth`（决策点计）为唯一前瞻控制；退化环用路径签名去重兜底为 `[-1,+1]`。
